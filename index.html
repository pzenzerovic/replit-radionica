Što je vibe coding?

Filozofija i principi novog pristupa razvoju aplikacija

U veljači 2025. istraživač Andrej Karpathy (suosnivač OpenAI-a) opisao je pristup koji mnogi već primjenjuju: „Potpuno prepuštam kodu. Prihvaćam vibes. AI gradi, ja usmjeravam." Taj opis dao je ime novom načinu rada s računalima.

🎯
Definicija

Vibe coding je pristup razvoju softvera u kojemu čovjek opisuje što želi postići prirodnim jezikom, a AI piše i popravlja kod. Čovjek upravlja vizijom, testira rezultat i iterira — ali ne piše kod ručno.

5 vještina efektivnog vibe codinga

Replit i DeepLearning.AI definirali su okvir od pet temeljnih vještina:

🧩 Koristi okvireIskoristi gotove alate i API-jeve umjesto da gradiš od nule

Zlatna pravila vibe codinga

  • Plan mode za složene projekte. Prije nego Agent počne graditi nešto veće, prebacite se u Plan mode. Opišite što želite, uskladite pristup — i tek onda kliknite Start Building. Štedi kredite i sprečava krivi smjer.
  • Počnite jednostavno. Opišite minimalnu verziju aplikacije. Kompleksnost dodajte iterativno, korak po korak.
  • Budite specifični. „Napravi lijepu stranicu" je loš prompt. „Napravi stranicu s bijelom pozadinom, plavim naslovom i tablicom s 5 podataka" je dobar prompt.
  • Testirajte odmah — i na mobitelu. Čim AI završi, kliknite Preview i provjerite radi li aplikacija. Koristite Screen size u Preview panelu za mobilni prikaz.
  • Checkpoint = spasenje. Svaki put kad nešto radi — napravite checkpoint. Uvijek se možete vratiti na tu verziju.
  • Doom loop? Plan mode pa rollback! Ako AI ne može popraviti grešku u 2 pokušaja, prebacite se u Plan mode za dijagnozu. Ako ni to ne pomogne — rollback na zadnji checkpoint.

Replit: sučelje i modovi

Pregled platforme i njezinih ključnih komponenti

Replit je platforma u oblaku koja u jednom tabu preglednika objedinjuje sve: editor koda, AI agenta koji gradi aplikacije, pregled u živo i objavu na internet. Ništa se ne instalira — sve radi u pregledniku.

🤖

Replit Agent

Jedini AI alat u Replitu. Opisujete aplikaciju prirodnim jezikom, Agent gradi cijelu strukturu. Radi u Lite i Autonomous modu. Razumije i hrvatski.

🗺️

Plan mode

Mod unutar Agenta gdje AI ne mijenja kod — samo razmišlja s vama. Aktivira se iz Plan / Build padajućeg izbornika u chat polju.

📌

Checkpoints

Automatski „save pointovi" projekta. Rollback = povratak na bilo koji checkpoint jednim klikom. Na besplatnom planu dostupno je prvih 10.

🚀

Deployments

Objavite aplikaciju jednim klikom. Static deploy je besplatan i daje javni URL (npr. moja-app.replit.app).

Tlocrt sučelja

Kad otvorite Repl (projekt), vidite tri zone:

  • L
    Agent panel (lijevo)
    Ovdje pišete promptove. U donjem lijevom kutu je Plan / Build dropdown — ključni izbornik. Build = gradi kod. Plan = samo razmišlja, bez izmjena.
  • S
    Editor i datoteke (sredina)
    Vidite kod koji je Agent generirao. Ne trebate ga mijenjati ručno — dovoljno je znati da postoji.
  • D
    Preview panel (desno)
    Živi prikaz aplikacije. Gumb Screen size u alatnoj traci omogućuje testiranje mobilnog prikaza. Ikona vanjskog linka otvara aplikaciju u novom tabu.

Hrvatski blagdanski kalendar

Kompletan Replit workflow — korak po korak

Ovaj primjer provodi vas kroz cijeli Replit workflow — od prazne stranice do objavljene aplikacije s pravim podacima. Svaki korak demonstrira jednu ključnu funkcionalnost platforme.

Gradimo web-aplikaciju koja dohvaća sve hrvatske državne blagdane za 2026. iz javnog API-ja i prikazuje ih s odbrojavanjima i vizualno istaknutim sljedećim blagdanom.

1
Pokretanje projekta

Idite na replit.com i prijavite se. Na početnoj stranici vidite centralni okvir s pitanjem „Hi [ime], what do you want to make?" — tu počinje svaki novi projekt.

Početna stranica Replita s centralnim poljem za unos. Replit predlaže kategorije projekata, ali vi ćete opisati što trebate vlastitim riječima.
2
Pisanje inicijalnog prompta

U polje za unos upišite prompt koji opisuje aplikaciju. Ključno je uključiti konkretan URL API-ja — Agent ga koristi kao izvor podataka. Možete otvoriti URL u novom tabu i vidjeti točno koje podatke Agent dobiva: date.nager.at/api/v3/PublicHolidays/2026/HR

✏️ Upišite u polje za unos
Napravi web aplikaciju koja prikazuje sve hrvatske blagdane u 2026. godini. Koristi Nager.Date API — URL za dohvat podataka: https://date.nager.at/api/v3/PublicHolidays/2026/HR Za svaki blagdan prikaži: - Datum u formatu DD.MM.YYYY. - Naziv blagdana na hrvatskom (polje "localName") - Koliko dana je ostalo do tog blagdana - Oznaku je li prošao ili je nadolazeći Koristi crvenu i bijelu boju. Neka bude vizualno atraktivno.
Prompt unesen u polje za unos — vidljiv je opis aplikacije i URL API-ja. Replit je prepoznao API URL i nudi brzi pregled sadržaja.
3
Agent planira i gradi

Nakon slanja prompta, Agent prikazuje što namjerava napraviti i počinje graditi aplikaciju. Ovaj proces traje 1–3 minute. Pratite poruke u lijevom panelu — Agent opisuje svaki korak koji poduzima.

Agent je prepoznao prompt, sažeo ga i počeo graditi. Desno se prikazuje editor s datotekama koje Agent kreira. Ne trebate ništa raditi — samo čekajte.
4
Prva gotova verzija

Kad Agent završi, Preview panel desno prikazuje radnu aplikaciju.

Aplikacija prikazuje 14 hrvatskih blagdana dohvaćenih s API-ja — datumi, nazivi, odbrojavanja i oznake. Gumb "Open Publishing" omogućuje objavu na javnom URL-u.
🔧
Odabir Agent moda

Za daljnji rad kliknite na padajući izbornik u Agent panelu. Preporučuje se Autonomous – Economy za gradnju novih funkcija, i Lite za sitne ispravke poput promjene boje.

Pregled dostupnih Agent modova. Autonomous Economy preporučen je za gradnju projekata uz razumnu potrošnju kredita.
5
Iteracija dizajna — Canvas mode

Replit ima Canvas mode koji omogućuje generiranje vizualnih dizajn varijanti aplikacije. Agent izrađuje nacrte paralelno — desktop i mobilni prikaz za svaku varijantu — koje potom možete pregledati i odabrati za izgradnju.

Upišite prompt na engleskom (Canvas mode bolje reagira na engleski):

✏️ Upišite u Agent chat
Make 2 variations of the design of the app you built. Use minimalistic clean design. Disregard previous colors. For each design show me the desktop and mobile view.
Agent gradi četiri okvira istovremeno — desktop i mobilni prikaz za svaku varijantu. Na platnu se pojavljuju radni okviri koji se popunjavaju u realnom vremenu.
6
Pregled dizajn varijanti

Kad Agent završi, na platnu su prikazane obje varijante — svaka u desktop i mobilnoj verziji. Možete usporediti estetiku i čitljivost i odlučiti koja bolje odgovara vašoj primjeni.

Varijanta 1 (Airy Light) — svjetla pozadina, prostrana tipografija. Varijanta 2 (Dark Structured) — tamna pozadina, precizniji prikaz datuma. Obje prikazane u desktop i mobilnoj veličini.
7
Odabir i izgradnja dizajna

Kliknite na varijantu koja vam se sviđa da je selektirate, a zatim iz padajućeg izbornika odaberite Build this design.

Odabir opcije "Build this design" na selektiranoj varijanti. Agent će implementirati vizualni stil iz nacrta u stvarnu aplikaciju.
8
Aplikacija ažurirana prema nacrtu

Agent primjenjuje odabrani dizajn na živu aplikaciju. API podaci ostaju isti — mijenja se samo vizualni prikaz.

Aplikacija sada vizualno odgovara odabranom nacrtu — neutralna paleta, čista tipografija. Podaci o blagdanima i odbrojavanjima identični su kao u prvoj verziji.
9
Otkrivanje grešaka — Plan mod

U kompleksnijim aplikacijama greške su neizbježne. Kad se pojavi problem (npr. krivi broj dana do blagdana, greška u prikazu), prebacite se u Plan mod prije nego tražite ispravak. Agent analizira kod bez ikakvih izmjena i predlaže konkretan plan.

Agent u Plan modu identificirao je bug i stvorio konkretan task plan. Prikazano je što treba promijeniti, gdje i zašto — bez ijedne izmjene u kodu.
10
Detalji plana ispravka

Plan mod prikazuje detaljan opis greške, njezin uzrok i predloženo rješenje. Tek kad prihvatite plan klikom na Build here, Agent gradi ispravak. Ovaj pristup sprečava da Agent napravi više štete nego koristi.

Detalji plana: točno koji file treba promijeniti, koji je uzrok greške i kako izgleda ispravna logika. Odobravanjem plana Agent gradi ispravak.
11
Testiranje na mobilnim uređajima

U Preview panelu kliknite ikonu Screen size u gornjoj traci. Otvara se padajući izbornik s popularnim uređajima — iPhone, Android, tableti. Provjerite aplikaciju na barem jednom mobilnom profilu.

Mobilni prikaz aplikacije — layout se automatski prilagođava malom ekranu. Vidljivi su blagdani s produženim vikendom i svi detalji.
Padajući izbornik Screen size nudi sve popularne uređaje: iPhone modele, Pixel, Samsung Galaxy. Svaki odabir trenutno mijenja širinu Preview prozora.
12
Rollback na checkpoint

Ako iteracija pođe naopako — Agent uvede novu grešku ili aplikacija prestane raditi — rollback na checkpoint vraća sve u ispravno stanje. Kliknite na ikonu checkpointa u Agent panelu, pronađite željenu verziju u listi i kliknite Rollback.

Modal za rollback prikazuje screenshot aplikacije u tom trenutku i listu datoteka koje će se vratiti. Rollback je siguran — ne gubi se ništa osim izmjena napravljenih nakon tog checkpointa.
✅
Sažetak naučenog

U ovom projektu ste prošli: pisanje prompta s API URL-om, autonomnu gradnju, iteraciju dizajna kroz Canvas mode, Plan mode za dijagnozu grešaka, testiranje na mobilnim uređajima i rollback na checkpoint. Sve ove vještine primjenjuju se na svaki projekt koji ćete graditi u Replitu.

Kviz iz školskog predmeta

Iterativno građenje — primjer za samostalan rad

Ovaj projekt funkcionalno je sličan interaktivnim kvizovima koje smo ranije gradili pomoću Claude Artefakata. Temeljna razlika: aplikacija u Replitu dobiva vlastitu javnu adresu na internetu — URL koji možete podijeliti s učenicima ili kolegama, neovisno o Claude ili ChatGPT sučelju.

Primjer demonstrira iterativno građenje — dodajete funkcije korak po korak, svaki put provjeravate rezultat i spremate checkpoint.

Korak 1 — Osnova

✏️ Upišite u Agent chat
Napravi web kviz s 5 pitanja iz [VAŠ PREDMET]. Svako pitanje neka ima 4 ponuđena odgovora (A, B, C, D). Nakon odabira odgovora odmah pokaži je li točan ili netočan. Svi tekstovi na hrvatskom jeziku.

Korak 2 — Dodajte bodovanje

✏️ Nastavak — nakon checkpointa
Dodaj bodovanje: za svaki točan odgovor 1 bod. Na kraju kviza prikaži ukupan rezultat (npr. "Postigao si 4/5 bodova!") i kratku poruku ovisno o rezultatu.

Korak 3 — Timer (opcionalno)

✏️ Opcionalni korak
Dodaj odbrojavanje od 30 sekundi po pitanju. Ako istekne vrijeme, pitanje se automatski označi kao netočno i prijeđi na sljedeće.
📌
Checkpoint savjet

Napravite checkpoint nakon svakog koraka koji radi. Ako korak 3 pokvari nešto iz koraka 2, možete se odmah vratiti na checkpoint između njih.

Kako pronaći nove izvore podataka

Alati i tehnike za samostalno istraživanje

Kad razumijete što je API i kako ga koristiti, evo kako pronaći nove izvore za bilo koji predmet ili temu koja vas zanima.

Metoda 1: GitHub public-apis lista

📋
Najkorisniji resurs

Repozitorij github.com/public-apis/public-apis — kurirana lista s 400+ besplatnih API-jeva u 48 kategorija. Više od 419.000 GitHub zvjezdica.

  • 1
    Otvorite stranicu i koristite Ctrl+F
    Potražite svoju kategoriju: „weather", „science", „animals", „books", „music"...
  • 2
    Filtrirajte po stupcu „Auth"
    Tražite No u stupcu Auth — bez API ključa. HTTPS treba biti Da, CORS treba biti Yes.
  • 3
    Kliknite link i otvorite dokumentaciju
    Svaki unos ima link na dokumentaciju s konkretnim URL-ovima za testiranje.

Metoda 2: Testiranje u pregledniku

Zalijepite URL u adresnu traku. Ako vidite tekst koji počinje s { ili [ — API radi.

🦊

Firefox

Ima ugrađen JSON viewer koji automatski formatira i oboji odgovor bez ekstenzija.

🌐

Chrome / Edge

Instalirajte besplatnu ekstenziju „JSON Viewer" iz Chrome Web Storea.

Metoda 3: Pitajte Replit Agent

✏️ Primjer prompta
Trebam besplatan API koji ne zahtijeva registraciju niti API ključ, a koji daje podatke o [TEMA]. Preporuči 2-3 opcije s primjerima URL-ova koje mogu testirati u pregledniku.
